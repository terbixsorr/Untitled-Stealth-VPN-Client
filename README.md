# 🛡️ Untitled Stealth — VPN & Proxy Browser Extension

**Untitled Stealth** — это кроссбраузерное расширение (Manifest V3) для умного обхода блокировок и маршрутизации прокси-трафика. Совместимо с Google Chrome, Яндекс Браузером, Microsoft Edge, Brave, Opera и Mozilla Firefox.

---

## ✨ Возможности

- 🚀 **Умная маршрутизация (Smart PAC):** Проксируются только заблокированные сайты (YouTube, Discord, Instagram, Twitter/X, Rutracker и др.). Банки, Госуслуги и локальные сайты работают напрямую без потери скорости.
- 🌐 **Глобальный режим (Global):** Направление 100% трафика браузера через прокси.
- ⚡ **Прямая интеграция с Happ / Xray / Sing-box:** Работает со стандартными портами локальных ядер (`127.0.0.1:10808` и `127.0.0.1:2080`).
- ➕ **Добавление сайта в один клик:** Кнопка «+ В список» прямо в окне расширения на текущей вкладке.
- 📶 **Встроенный замер пинга (Latency):** Быстрая проверка отклика прокси в миллисекундах.
- 🎨 **Стильный Cyberpunk/Stealth дизайн:** Минималистичный тёмный интерфейс с неоновой анимацией статуса.

## 📦 Как установить в браузер (Chromium: Chrome, Яндекс, Edge, Brave)

1. Откройте страницу расширений в браузере:
   - В **Google Chrome**: перейдите по адресу `chrome://extensions`
   - В **Яндекс Браузере**: перейдите в `browser://tune` или `chrome://extensions`
   - В **Microsoft Edge**: перейдите по адресу `edge://extensions`
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку:
   ```
   C:\лаунчер
   ```
5. Закрепите значок с буквой **U** на панели расширений браузера!

---

## 🦊 Как установить в Mozilla Firefox

1. Откройте `about:debugging#/runtime/this-firefox` в адресной строке.
2. Нажмите кнопку **«Загрузить временное дополнение...»** (Load Temporary Add-on).
3. Выберите файл `manifest.json` в папке `C:\лаунчер`.

---

## ⚙️ Связка с лаунчером Happ / Xray / VLESS

1. Запустите ваш лаунчер (**Happ**, **V2rayN**, **Sing-box** или **Hiddify**).
2. Подключитесь к вашему VLESS/Shadowsocks серверу в лаунчере.
3. Откройте **Untitled Stealth** в браузере и нажмите большую круглую кнопку включения.
4. По умолчанию расширение настроено на локальный порт SOCKS5 `127.0.0.1:10808` (стандартный для Happ / Xray).
5. Если вы используете другой порт, откройте настройки (шестерёнка в правом верхнем углу) и выберите или добавьте ваш порт (например, `127.0.0.1:2080` для Sing-box).
